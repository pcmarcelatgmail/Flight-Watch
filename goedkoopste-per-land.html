Aankomstbord · land-scan

Welke luchthaven in dat land is het goedkoopst?

Vul je vertrekpunt, datum(s) en klasse in, geef een land op als bestemming, en de app zoekt via de Sky‑Scrapper (AirScraper) API de 5 goedkoopste aankomstluchthavens in dat land (of minder, als er minder beschikbaar zijn).

API-sleutel

Je sleutel wordt alleen gebruikt om rechtstreeks vanuit jouw browser naar sky-scrapper.p.rapidapi.com te bellen — hij gaat nergens anders naartoe. Nog geen sleutel? Maak gratis een account op rapidapi.com en abonneer je (gratis BASIC-plan) op "Sky Scrapper".

Zoekopdracht

Elke aangevinkte luchthaven kost minimaal 1 API-call. De gratis BASIC-plan van RapidAPI geeft je 100 calls/maand — zet er gerust een paar uit om te sparen.
Gebouwd rond de Sky‑Scrapper (AirScraper) API op RapidAPI. De luchthavenlijst per land komt uit de eigen zoeksuggesties van de API — bij grote landen kan dat soms een gegroepeerde stadscode zijn in plaats van één losse luchthaven. Prijzen komen rechtstreeks van de API en kunnen afwijken van de uiteindelijke boekingsprijs. Deze pagina slaat verder niets op of door buiten je eigen browser.
